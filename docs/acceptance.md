Earlier attempts are retained as useful limitations:

- `Auto` over Messages returned HTTP 400 for text and 429 for stream/tools; this did not pass.
- `anthropic/claude-haiku-5-5` passed text, streaming and actual Claude Code single-turn use
  (9.128 s), but its tool-roundtrip attempt returned HTTP 502 after approximately 60 seconds.
- Switching to the explicit verified model passed all three native protocols and tool cases.
  The project did not change IteraCompute's production routing or suppress these failures.

Native one-turn success proves routing and an actual reply. It does **not** establish every
client's autonomous tool loop, long session, compaction, vision, sandbox behavior or error recovery.
The API tool round trip does not substitute for each native client's real filesystem tool loop.
WorkBuddy still needs an installed desktop app, restart, task-picker selection and disposable
workspace acceptance. CC Switch desktop import click-through remains a separate optional test.

## Local automated evidence

Rechecked on **2026-11-17**: the local suite passes **52 tests** with pinned Magpie and installed native CLI opt-ins enabled.
It covers the independent UI management API, private settings, no inherited-key fallback,
Host/Origin/control-token checks, fixture requests, exact native restoration, later-edit
conflicts, symlink preservation, WorkBuddy list/object formats, and stale Hermes route/key fields.

active provider and live key, with temporary credentials removed afterward.

a local fixture backend. Hermes 0.23.1 was separately installed and passed the same independent
configuration/fixture path (7.631 s) before the real-provider run. Optional Magpie tests verify
its pinned engine translating a Chat-only source across all three protocols, sync idempotence
and its own five native adapter restore paths. No model key is required for fixture tests.

includes the packaged HTML/CSS/JS assets, launchers and blank template; private key files are excluded.
Manual real-provider and installed-client acceptance was performed on Linux. Separately, the
[first enabled GitHub CI run](https://github.com/IteraCompute/agent-connect/actions/runs/44015209371)
passed on 2026-11-17: Ubuntu, macOS and Windows with Python 3.11/3.14, quality/build, pinned Magpie
fixture tests and the required aggregate `checks` job. These OS unit/fixture runs do not establish
real-provider or installed desktop-client acceptance on macOS/Windows.
