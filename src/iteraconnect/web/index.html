在 Visual Studio 中添加模型

  1. 在 Windows 的 Visual Studio 2026（18.10 或更高版本）打开 Copilot Chat，在模型菜单选择“管理模型” → “添加模型”。
  2. 选择 Custom Endpoint，或支持自定义地址的 OpenAI。选择 Completions 格式，用下面三项填写并保存。
  3. 在 Agent 模式的新对话中选中该模型，发送 Reply with exactly ITERACONNECT_OK.，核对回复。

需要移除时，在同一模型菜单删除此端点。
